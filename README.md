# أدوات KhanWars

مجموعة أدوات مستخدم وتحليلات محلية للعبة KhanWars، تشمل userscripts، وفهارس لنقاط AJAX في واجهة اللعبة، وأدوات لجمع ملفات الواجهة العامة.

## محتويات المستودع

- `userscript/` — السكربتات ووثائق استخدامها.
- `analysis/` — فهارس وملفات تحليل إجراءات اللعبة.
- `archive/public/` — ملفات الواجهة العامة المؤرشفة للتحليل.
- `tools/` — أدوات جمع الملفات وخدمة userscript محلياً.

## البدء

راجع [`userscript/README.md`](userscript/README.md) لتثبيت السكربتات وإعدادها. أداة جمع الملفات موثقة في [`tools/collect_public.py`](tools/collect_public.py).

> استخدم الأدوات على مسؤوليتك، وتحقق من قواعد اللعبة قبل تشغيل الأتمتة أو إرسال إجراءات تغيّر حالة اللعب. لا يتضمن هذا المستودع لقطات الصفحات الخاصة أو ملفات تسليم العمل المحلية.
